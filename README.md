# サービスの概要
Qiitaをイメージしたマークダウン記法が使える記事投稿アプリです。

# サービスを開発した背景
スクールで学習したRuby、Railsの実践課題として取り組みました。

# 画面や機能の説明
・ユーザー登録とログイン機能、投稿のCRUD機能といった基本機能を実装
・gem「devise」を活用しログイン機能を実装
・AI開発ツール「Cursor」を導入

# 主な使用技術
## バックエンド
・Ruby 3.1.3 ・Rails 6.1.7.10 ・HTML ・CSS ・Git ・RSpec ・Docker ・devise

## フロントエンド
・JavaScript
